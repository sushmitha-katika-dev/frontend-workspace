HTML

HTML (HyperText Markup Language) is used to create the structure of a webpage.
It uses tags to add headings, paragraphs, images, links, tables, and forms.
Think of HTML as the skeleton of a webpage that gives it its basic shape.
CSS (Cascading Style Sheets) styles the webpage by adding colors, fonts, backgrounds, borders, and spacing.
If HTML is the skeleton, CSS is the clothing that makes the webpage look attractive.
